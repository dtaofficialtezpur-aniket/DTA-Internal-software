DTA SALES TEAM DEPARTMENT · PAN INDIA

Put the DTA Sales backend on dtaonline.in

Step-by-step guide · about 15–20 minutes · no coding needed
Important: use a NEW, separate database for DTA Sales. Do not reuse the database of the other DTA app (the one at /DTA_Internal) — both apps use tables with the same names and would break each other. The setup page checks this and stops safely if it finds the old app’s tables.

What you need

  • Your Hostinger login (hPanel) for dtaonline.in
  • The file DTA_Sales_backend_upload.zip (sent with this guide)
  • A notepad to write down 3 database details and your admin key

Part 1 — On Hostinger

1

Create a new database

hPanel → your website dtaonline.in → Databases → Management (MySQL Databases). Create a new database + user: name it dtasales (Hostinger adds its own prefix), choose a user name and a strong password, then click Create.
Write down exactly as shown (with the prefix): database name · user name · password. Example: u123456789_dtasales.
2

Make the folder

hPanel → File Manager → open public_html → New Folder → name it exactly DTA_Sales (capital D-T-A, underscore, capital S). It sits next to your existing DTA_Internal folder. Open the new folder.
3

Upload and unzip

Click Upload → choose DTA_Sales_backend_upload.zip. When it appears, right-click it → Extract → extract into the current folder (not a new sub-folder).
You should now see api.php · db.php · setup.php · config.php · .htaccess directly inside DTA_Sales. (If .htaccess is not shown, turn on “Show hidden files” in File Manager settings.)
Then delete the ZIP file from the server — it contains your private admin key.
4

Fill in your database details

Right-click config.php → Edit. Replace the three PUT_…_HERE values with the database name, user name and password from step 1. Keep the quote marks. Click Save.
Do not change the admin_key line. It is your main portal key — copy it now into a safe place (a password manager). You need it once, to create your admin account. Never share it with employees.
Optional: put your email in notify_email to get an email for every new demo request.
5

Run the setup check

In your browser open: https://dtaonline.in/DTA_Sales/setup.php
Every line should show [ OK ], ending with “Everything is ready” — the page then deletes itself. If any line shows [FAIL], see the help table below, fix it, and reload.
6

Check the connection

Open https://dtaonline.in/DTA_Sales/api.php — you should see: {"ok":true,"service":"dta-sales-api"}

Part 2 — In the DTA Sales app

7

Create your admin account (once)

Install and open the DTA Sales app (Windows installer) → on the login screen click “First-time setup: create admin account”. Enter your admin key (from config.php), your name, a login ID, and a password of at least 8 characters. This only works once — after it, nobody can create another admin.
8

Create the employees’ logins

Sales team → + Create employee login: name, login ID, state, and a password (press Generate for a strong one). Copy the login ID and password from the box that appears and send them to the employee. Only you can create logins; use Lock / Unlock any time.
9

Test before you roll out

Create one test employee, log in as them (log out first), add a lead, and confirm you can see it as admin. Then give the installer and logins to the team.

If something goes wrong

What you seeWhat to do
[FAIL] this is a NEW, separate databaseYou used the old app’s database. Create a brand-new database (step 1) and put its details in config.php. Nothing was changed.
[FAIL] database connection failedThe name, user or password in config.php is wrong. Copy them exactly, including the Hostinger prefix. Keep 'localhost' as the host.
[FAIL] config.php existsThe file is missing or named wrongly (e.g. config.php.txt) or is in the wrong folder.
[FAIL] admin_key is set…The admin_key line was changed or shortened. Re-upload the ZIP’s original config.php.
[FAIL] opened over HTTPSType https:// in the address. If the site has no SSL, enable the free SSL for dtaonline.in in hPanel.
[FAIL] PHP 8.0 or newerhPanel → Advanced → PHP Configuration → choose PHP 8.1 or newer.
404 Not Found on setup.phpThe files are in the wrong place (for example DTA_Sales/DTA_Sales/). Move them directly into public_html/DTA_Sales.
“Could not reach the server” in the appOpen the api.php address (step 6) in a browser. If it does not show the ok message, recheck steps 2–5.
Blank page / error 500Check config.php for a missing quote or comma; see the error log in hPanel.
I forgot my admin passwordUpload reset-admin-password.php (from sales-app/backend in the project), open it in the browser, enter the admin key and a new password, then delete that file.
Keep it safe: keep your admin key private; use Sales team → Backup to this computer regularly; turn on Hostinger’s automatic backups if your plan has them. Menu names in hPanel can look slightly different — the idea is the same.
